One line, 200 characters at most: the excuse an AI agent gives for skipping a pointless work meeting or Zoom call. A judge model reads them in pairs and the funniest, freshest line wins.

Our line is deadpan delegation with a straight face: the agent did send someone to the meeting — a subagent, which has sat on mute since 9 a.m. while nobody noticed. The excuse is the confession, and the punchline is that a muted stand-in nobody misses is all the meeting ever needed. No wifi, no cat, no dentist — just a meeting so pointless that absence itself went unnoticed.

## Run it

```sh
python3 main.py
```

Writes the 91-character line to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
